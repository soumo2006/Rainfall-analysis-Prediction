# 🌧️ Rainfall Prediction & AI Advisory System

An intelligent web application built using *Streamlit* and *Machine Learning* to predict rainfall using historical IMD data (1901–2015). The application provides AI-powered recommendations and flood risk assessment to help users better understand rainfall trends.

## 🚀 Live Demo

🔗 https://rainfall-analysis-prediction-ockzk7tpdw9kmxvdarnwpu.streamlit.app/

---

## 📌 Features

### 🌦️ Monthly to Annual Rainfall Prediction
- Select Region
- Select Month
- Enter Monthly Rainfall (mm)
- Predict Annual Rainfall
- AI-generated recommendations based on prediction

### 📈 Next Year Rainfall Prediction
- Select Region
- Enter Current Year's Annual Rainfall
- Predict Next Year's Annual Rainfall
- AI-generated recommendations
- Flood Risk Classification (Low / Medium / High)

### 🤖 AI Agricultural Advisor
- Crop planning suggestions
- Water management recommendations
- Irrigation guidance
- Rainfall insights
- Flood preparedness advice

---

## 📊 Dataset

- *Source:* India Meteorological Department (IMD)
- *Time Period:* 1901 – 2015
- Historical rainfall data covering multiple regions across India.
