Rainfall Prediction System (Machine Learning + Streamlit)

📌 Overview

This project is a Machine Learning-based web application that predicts rainfall using historical data from India (1901–2015).
The model is deployed using Streamlit, allowing users to input features and get real-time predictions.

🧠 Machine Learning Details

- Algorithm: Linear Regression
- Preprocessing:
  - Feature Scaling
  - Label Encoding
- Model Files:

  - "label_encoder.pkl"
